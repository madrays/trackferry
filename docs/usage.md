# 使用说明

## 音箱的三种模式

| 模式 | 会做什么 |
| --- | --- |
| 不接入 | 不读它的对话，也不控制它 |
| 观察 | 记录点歌，并写出如果接管会放什么。不出声 |
| 接管 | 曲库或线上有的歌由 TrackFerry 放，其余交给小爱 |

新发现的音箱默认不接入。能不能选接管由 `TRACKFERRY_TAKEOVER` 放行。

## 能听懂的说法

| 想做 | 可以这样说 |
| --- | --- |
| 点一首歌 | 播放周杰伦的晴天 · 我想听周杰伦唱的稻香 · 来一首后来 |
| 指定版本 | 播放晴天现场版 |
| 听一位歌手，一直放 | 我要听陈奕迅的歌 · 播放周杰伦的歌 |
| 随便听 | 放点音乐 · 随便放一首歌 |
| 接着换歌手 | 换成周杰伦的版本 · 不是这个，放邓紫棋的 · 换个版本 |
| 连播收藏 | 播放我的收藏 · 随机播放我喜欢的歌 |
| 连播专辑 | 播放专辑叶惠美 · 播放这张专辑 |
| 连播歌单 | 播放测试歌单 · 播放歌单测试 |
| 收藏正在放的歌 | 收藏这首歌 · 取消收藏 |
| 加入歌单 | 把这首歌加入测试歌单 · 从测试歌单里删掉这首歌 |
| 控制 | 暂停 · 继续 · 停止，由小爱执行，TrackFerry 跟着调整；说“停止”连播也结束；连播时还可以说下一首、上一首 |

“换版本”指 15 分钟内点过的上一首。新闻、故事、电台、闹钟等不算点歌，直接由小爱处理。管理页的“怎么说”可以输入一句话，看它被怎么理解。

## 一首歌怎么选出来

1. **曲库**：先找完全对上的。
2. **同名有多位歌手**：依次看收藏、线上对原唱的意见、匹配程度、曲库里谁的歌多。页面会写出依据，并列出其他歌手。
3. **线上**：同时问酷我、酷狗、咪咕、网易云，取最先给出的完整版。曲库和线上都没有完全对上的，再按听错一个字先曲库后线上找：歌名四个字以上可以错、多或少一个字，说了歌手的三个字就行；歌手三个字以上也可以错一个字。歌名和歌手不会同时猜，数字、“不”“没”这类字不猜。没有权限的会员歌和试听片段会跳过。在“设置 → 线上音源”用网易云音乐 App 扫码登录后，你的账号能完整听的歌也能放，也和别的歌一样进缓存。扫码提示要额外验证（8821）时，点“粘贴凭据”：在电脑浏览器登录 music.163.com，按 F12 复制 Cookie 里 MUSIC_U 的值贴进来。
4. **小爱**：前面都没有，或说的不是点歌，就由小爱处理。

## 放歌时

- 音量会短暂归零再恢复，这是为了不漏出小爱自己的播放。程序意外退出，下次启动会补上恢复。
- 和小爱说别的话，歌会停下，等小爱说完从断点接着放。
- 按音箱上的暂停键也行，再按播放键从原处接着放。
- 说“暂停”后，说“继续播放”回到断点；说“停止”就结束，连播也一起结束。小爱去放了别的内容，歌不会再自动续上。
- 页面上的播放、暂停、停止和说话效果一样，在“此刻”选中音箱，或到音箱页操作。电脑上除“此刻”外每页底部都有一条播放条，可以暂停、下一首、调音量，点歌名回到“此刻”。
- 单独点一首歌时默认放完即停。网页里的专辑、歌手、收藏和歌单默认按列表顺序循环。
- 播放方式在“此刻”或音箱页切换，每台音箱各记各的：随机播放、顺序循环、单曲循环。单曲循环对点的单首歌也有效，同样受“最长放多久”限制；改了方式，正在放的这首不受影响。口令点的歌单先随机挑一首开始，顺序循环时从它往后按顺序放。
- 上一首、下一首可以点按钮，也可以说。语音点的单曲可以用“下一首”随机换歌。小爱自己放的内容由小爱控制。

- **拖进度**：在“此刻”拖进度条，或点一句歌词。拖动时显示目标时间，确认定位后才更新播放位置。音箱需要重新取流并回读，进度前的 `≈` 表示估算；M4A 等不支持定位的曲目仍能播放。
- **播放列表**：点操作区右边的列表图标，看正在放的和后面的歌，点一首就放它，点叉移出，也可以停止播放。移出只影响这次播放，不动飞牛的歌单和音乐文件。
- **歌词**：本机播放按浏览器的音频时钟换行。点歌词右下角可以换字号，也可按 0.1 秒提前或延后；校准按曲目保存。挂载目录的歌曲可在同目录放同名 `.lrc`，例如 `潮汐来信.flac` 对应 `潮汐来信.lrc`。没有时间标记的歌词只显示文字。

## 在本机放

新开的网页默认放在本机。想换输出，在曲库或搜索里点“播放到”，选择音箱或本机。这个选择在当前标签页刷新后仍然有效。在“此刻”查看一台音箱只会切换正在查看的播放器。所选音箱已关闭接入或移出账号时，播放按钮会显示本机。

- 从专辑、歌手、收藏、歌单或“随手翻到的”点一首，就从这首起播放整个列表。筛选和滚动加载只影响页面显示。
- 从搜索结果或历史里单独播放一首，会开始新的播放队列。想保留现有列表，可以在歌曲菜单里选“下一首放”或“放到队尾”。单曲放完默认从曲库随机接着放，见下面的“连续播放”。
- 本机播放列表可以调整待播顺序，或仅保留当前曲目。
- 进度条会显示浏览器已缓冲的区间；暂停时定位仍保持暂停。系统媒体面板是否显示切歌或快进快退，由浏览器和操作系统决定。
- 每个浏览器各放各的，列表记在浏览器里，刷新后停在原来的地方。
- 不写进点歌记录，也不影响音箱。iPhone 不允许网页调音量，用侧边的音量键。
- 关掉页面就停。

## 连续播放

放完一首接着放什么，音箱、本机网页、电视和 DLNA / Chromecast 投放都按同一套规则走，设置只存在服务端一份：

| 点了什么 | 放什么 |
| --- | --- |
| 歌手（说“放周杰伦的歌”，或在歌手页播放） | 这位歌手在曲库里的全部歌 |
| 专辑 | 整张专辑 |
| 收藏、歌单 | 里面的全部歌 |
| 其余：搜到的一首、在线歌、说“放一首晴天”“来点音乐”、随手翻到的几首、接力过来只有一首 | 先放点的，再随机接上 |

列表循环播放，直到换歌或到达最长时间。

在“设置 → 连续播放”里：

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 点的歌放完接着随机放 | 开 | 管上表最后一行；关掉就放完即停，随手翻到的只放那几首 |
| 随机从哪挑 | 整个曲库 | 也可以只挑“我的收藏”；收藏是空的就从整个曲库挑 |
| 最长放多久 | 3 小时 | 所有连播到时间就结束，正在放的那首会放完；可以设为不限 |

在本机放时想放完这首就停，在播放队列里点“仅保留当前曲目”。

## 从页面送歌到音箱

- **收藏、歌单、专辑、歌手、随手翻到的**：在曲库的“播放到”选一台音箱，再点整个列表的播放键，或点列表内的一首歌。音箱设为观察或接管都可以。
- **下一首放、放到队尾**：在歌曲的三个点菜单选音箱和排队方式。当前没有队列时，所选歌曲会立即开始播放。
- **名字难念、识别不准的歌**：在搜索页点“在线源”，搜酷我、酷狗、咪咕、网易云，点一下就送到音箱。送过的歌照常缓存。

## 压住小爱的回答

接到点歌时先打断小爱，同时把音量降到零遮住打断生效前的那一小段。接管的音箱在音箱页可以换档，型号不支持米家静音的没有“加强”：

| 档位 | 做法 |
| --- | --- |
| 普通 | 音量调到零并打断，出歌最快 |
| 加强 | 再加一道米家静音和暂停。LX06 没有这一档，OH2P 默认用这一档 |
| 等小爱说完 | 一直静音，估计小爱说完了再放歌，出歌慢一些 |

普通压不住就换加强，没有这一档或还不行就换等小爱说完。OH2P 小爱说话时打断不了（固件如此，只有按实体键能停），不想听那段回答就选等小爱说完。小爱的话要先被读到才能打断，开头漏一点点属于正常。

## 听歌识别

程序靠反复读小米云端的对话记录知道你对音箱说了什么。在“设置 → 听歌识别”里可以按自己的情况组合：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 听音箱说的话 | 开 | 关掉后不再读对话记录，不会被小米限流；说话点歌、“下一首”这类口令没反应。从网页、电视、Home Assistant 送歌照常 |
| 多久读一次 | 2 秒 | 1 到 10 秒。越短，说完到出歌越快（平均多等半个间隔），但每台音箱每次都是一次小米云端请求，音箱多、间隔短容易被限流，表现为“读取失败”、点歌没反应。观察模式的音箱按两倍间隔读 |
| 没人说话时放慢 | 开 | 一台音箱一段时间没听到任何话（“多久没人说话算安静”，默认 10 分钟，可选 3 到 60 分钟），就按“放慢后多久读一次”读（默认 6 秒）；一听到话马上回到正常间隔，并再保持这么久。刚点过歌、还在等“换个版本”这类口令的音箱不放慢 |
| 被限流时所有音箱一起等 | 开 | 小米拒绝读取时整个账号一起暂停，从两倍间隔开始翻倍，最长 5 分钟，读通了马上恢复；期间只记一条日志 |
| 睡眠时段 | 关 | 设定的时段里（默认 01:00 到 07:00，可跨午夜）完全不读，夜里不白白请求 |

常被限流就先把间隔调长；家里只用网页送歌、不需要说话点歌，可以直接关掉“听音箱说的话”。

## 曲库多久同步一次

默认每 6 小时，在“设置 → 飞牛音乐”里可以改成 5、15、30 分钟或 1、3、12、24 小时，或关掉只手动同步。没有变化时只读一遍列表，不写数据库，常加歌选 5 分钟也没有负担。

## 收藏和歌单

- 读的是设置里登录的飞牛音乐账号的收藏和歌单，说的时候现读，刚加进去的也算；但歌要已经同步到曲库。
- 歌单名要说出“歌单”两个字。完全一致的优先，其次是名字里包含所说的，三个字以上允许听错一个字。只有一个歌单时可以不说名字。
- 中途暂停、和小爱聊天，继续后照样连播。说“停止”、点别的歌、让小爱放别的内容、从页面推歌、把音箱改为不接管，连播就结束。停了 15 分钟不再续。
- 放不了的歌自动跳过；连着三首音箱都没有放出来就停下。
- 程序重启后连播不会自动恢复，再说一次即可。
- 加入、移出只改飞牛音乐的歌单，不动音乐文件。线上找来的歌不在飞牛曲库里，加不进去。

## 家里多人一起用

- 全家用同一个管理密码。每台设备登录后自动起个名字（如“iPhone”“iPad”，重名自动加 2、3），在“更多 → 这台设备”里改成“客厅 iPad”“妈妈的手机”这样好认的名字。登录、改名、退出都只影响这一台，不会把别人踢下线；只有改管理密码会让所有设备重新登录。
- 每台设备各自记着：上次选的输出（下次打开还是它）、本机列表、均衡器、歌词大小。
- 全家共用：设置、收藏、歌单。歌单在飞牛音乐里建，建议每人建一份自己的，点歌时说或点自己的那份，互不打扰。
- 往音箱、电视、投放设备送歌后，“此刻”页和设备卡片会写“客厅 iPad 点的”。要是那台设备正在放别人点的歌，提示里会写“接替了某某在放的歌”，方便当面打个招呼。

## 管理页

| 页面 | 内容 |
| --- | --- |
| 此刻 | 正在放的歌、歌词、进度和播放列表；按天的点歌记录，手机上点右下角的图标打开，点一条看它什么时候、在哪台、说了什么，可以在原来那台或换个地方再放一次；试一句看会放什么，不出声 |
| 流转 | 一句话的全过程，实时或回放 |
| 怎么说 | 说法示例与解释，以及不用说话的操作从哪里点 |
| 搜索 | 曲库和在线源，点一下送到音箱 |
| 曲库 | 收藏、歌单、专辑、歌手，送到音箱或排到下一首 |
| 音箱 | 一台一行，写着在线、正在放什么和模式；点开设置模式、压住小爱的方式、无损转 MP3，看这个型号已知的问题，试一下接管。播放控制在“此刻”页 |
| 设置 | 账号、音源、连续播放、Home Assistant、密码、更新 |

登录时勾上“保存密码”，密码交给浏览器自己的密码库保存，180 天内不用再登录；不勾的话关掉浏览器就要重新登录。公用电脑上不要勾。

## 装到手机或电脑桌面

- **iPhone、iPad**：用 Safari 打开，分享 → 添加到主屏幕。1.5.0 之前添加过的，删掉图标重新添加一次，水面才会铺到状态栏下面。
- **安卓、电脑的 Chrome 或 Edge**：用 HTTPS 地址打开时，“设置 → 关于”会出现“装到桌面”。用 http 的局域网地址，浏览器不允许安装，只能添加快捷方式。
