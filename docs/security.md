# 隐私与安全

## 存了什么

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 点歌与播放控制口令 | 数据库 | 保留 180 天。其他对话只在内存里计数，不保存 |
| 听过的线上歌 | `data/cache`，或挂载的 `/cache/trackferry` | 默认最多 1 GB，到上限先删最久没听的，也可设为不限；可在“设置 → 线上音源”关闭或清空。不进飞牛音乐 |
| 小米登录凭据 | `data/private/xiaomi.json` | 0600。小米密码不保存，只以摘要形式在内存里停留到这次登录结束，最长 10 分钟 |
| 飞牛音乐会话 | `data/private/feiniu.json` | 0600。密码不保存 |
| 登录会话 | 数据库 | 每台登录的设备一条，只存令牌的 SHA-256 摘要和设备名字（自动起的或家人改的）。到期自动失效 |
| 管理密码 | 数据库 | PBKDF2-SHA256，60 万次。登录页的“保存密码”交给浏览器的密码库，TrackFerry 和页面都不存明文 |
| Home Assistant 令牌 | 数据库 | 只存 SHA-256 摘要 |
| 网易云会话 | `data/private/netease.json` | 0600。只有登录网易云后才有，退出时删除；只发给 music.163.com，不进日志和接口响应 |
| 脚本令牌 | `data/private/admin_token` | 0600 |

这些不进日志、接口响应和镜像。页面只显示打码的小米 ID。

## 连到哪里

| 目标 | 何时 | 发了什么 |
| --- | --- | --- |
| 小米 | 有音箱接入时，默认约每 2 秒一次（可在“设置 → 听歌识别”调整或关闭）；唤醒音箱时连米家的服务 | 你的小米会话 |
| 飞牛音乐 | 同步与放歌 | 你的飞牛会话 |
| 酷我、酷狗、咪咕、网易云 | 曲库没有，或需要判断原唱 | 歌名与歌手 |
| 电视、DLNA / Chromecast 设备 | 只在局域网里；配对或打开后 | 要放的歌和播放控制。设备从 `TRACKFERRY_URL` 取歌，取歌地址是一次性的随机地址 |
| GitHub | 每天两次，可关闭 | 读取版本信息；点“更新”时下载新版本。不带任何标识；可以单独设置代理 |

程序不收集统计或遥测数据。

## 保护措施

- 首次设置要用容器日志里的初始化码，避免局域网里其他人抢先设置。
- 登录失败 5 次停 15 分钟；写操作校验来源；Cookie 为 HttpOnly、SameSite=Strict。
- 全家共用一个管理密码，每台设备各有自己的会话：一台退出不影响别的设备；改管理密码会让所有设备重新登录。
- 飞牛的自签证书在登录时记住指纹，变了就拒绝连接。
- 音箱取歌用 128 位随机地址，6 小时过期，只能取到被选中的那一首。
- 在线更新要登录后手动确认，代理地址保存在 `data/private`，管理页不显示其中的密码；只安装带有项目签名的程序，每次启动都重新核对；不需要 Docker 权限。
- 容器只在启动的一瞬间是 root，用来把 `data` 交给普通身份；切换之后没有任何系统特权，也回不去，然后才读取 `data` 里的内容。文件系统只读，音乐目录只读。
- Home Assistant 接口默认关闭，有单独的令牌，只能看音箱状态和控制播放，打不开其他接口；换新或关闭时已有连接立即断开。口令、歌名会经这个接口给出去，Home Assistant 那边是否保存由它决定。
- 新版本只提示，不自动安装。

## 使用建议

- 只在局域网使用，不要把端口映射到外网。确需远程访问，走 VPN 或带登录与 HTTPS 的反向代理。
- 默认的 host 网络意味着程序能连到 NAS 本机的服务；不接受这一点，用备选的桥接方案。
- 备份文件含登录凭据，按密码对待。
